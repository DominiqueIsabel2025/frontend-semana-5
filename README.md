# Proyecto Semana 5 - Frontend 1

## Descripción

Proyecto desarrollado para la Semana 5 de la asignatura Frontend 1.

El objetivo es incorporar JavaScript al sitio web para mejorar su interactividad mediante la manipulación del DOM, eventos y consumo de datos externos utilizando Fetch API.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- DOM
- Fetch API
- GitHub
- GitHub Pages

## Funcionalidades implementadas

### Manipulación del DOM

El proyecto utiliza JavaScript para seleccionar y modificar elementos de la página.

Se utilizan métodos como:

- `getElementById()`
- `createElement()`
- `appendChild()`
- `textContent`

También se genera contenido dinámicamente mediante JavaScript.

### Eventos

Se implementaron diferentes eventos para mejorar la interacción:

- `click`: permite cambiar el mensaje de bienvenida.
- `mouseover`: aplica un efecto visual a la sección de bienvenida.
- `submit`: permite validar y procesar el formulario de contacto.

### Formulario

El formulario solicita el nombre del usuario.

Si el campo está vacío, se muestra un mensaje indicando que debe ingresar su nombre.

Si el usuario ingresa un nombre, se muestra un mensaje de confirmación.

### Fetch API

El proyecto utiliza Fetch API para obtener datos externos desde una API pública.

Los datos obtenidos se muestran dinámicamente en la página.

También se implementa manejo de errores mediante `.catch()`.

## Diseño responsive

El sitio utiliza CSS responsive para adaptarse a diferentes tamaños de pantalla, incluyendo computadores, tablets y dispositivos móviles.
